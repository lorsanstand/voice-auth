# voice-auth

## Биометрические контуры

Приложение поддерживает два независимых способа сравнения голоса:

- **MFCC** — текущий локальный контур, данные хранятся в коллекции `voice`;
- **ECAPA-TDNN** через `sherpa-onnx` — данные хранятся отдельно в коллекции `voice_ecapa`.

Векторы и профили между контурами не сравниваются. В интерфейсе у каждого контура свои регистрация, поиск, список и удаление.

## ECAPA-TDNN

Рабочая модель sherpa-onnx уже встроена в бинарник. Отдельно скачивать файл для обычного запуска не нужно:

```bash
go run ./cmd
```

При запуске встроенная модель временно извлекается в системную папку, потому что API sherpa-onnx принимает путь к ONNX-файлу. После завершения сервера временный файл удаляется.

При необходимости можно переопределить встроенную модель:

```bash
ECAPA_MODEL_PATH=/path/to/ecapa_tdnn.onnx go run ./cmd
```

Если внешняя модель не загрузилась, MFCC-контур всё равно продолжит работать, а ECAPA-контур будет отключён с сообщением в логах.
